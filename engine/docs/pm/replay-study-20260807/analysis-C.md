# m21: michiru(紫カタクリ) ○ − ● tikumaru(黄キッド OP10-099) — T20・556入力・最終は投了

## 1. ゲームストーリー（3行）
1. キッドは「毎エンド ライフ表向き→超新星1体アクティブ化+ブロッカー付与」で自己再生する壁（キラー/ST36-005/OP10-112/ボルサリーノ）を張り続け、ライフ回復（キラー・ボルサリーノ・ローで計+8）で消耗戦に持ち込んだ。
2. カタクリはプリン×3（2ドロー+踏み倒し）とドン循環（ST34-001/OP11-067のエンド時ドン追加）で息切れせず、T9・T11・T17の「壁の一掃ターン」を作って T11 にライフ4→0 の4点バーストを通した。
3. 以後キッドは回復（ボルサリーノ×2等）とブロックで9ターン粘るも、カタクリが毎ターン3〜6回攻撃（総計35回 vs 20回）で回復を上回り、T19に再びライフ0、T20の反撃も的確なカウンターで止められ投了。

## 2. 勝者（michiru）の勝ち筋
### 詰めターンの攻撃順序とドン配分（T19: 3点+最後のブロッカーKO, LOG367-400）
| 順 | アタッカー | ドン | パワー | 結果 |
|---|---|---|---|---|
| 1 | ST34-001 | 素 | 7000 | 通る（スルー、トリガーApooでリーダー7000化） |
| 2 | OP11-067 | +1 | 9000 | c2000×2で防がれる |
| 3 | ST34-001#2 | +3 | 10000 | c2000×2で防がれる |
| 4 | リーダー | +4+効果 | 10000 | 通る |
| 5 | リンリン | 素 | 12000 | 通る → ライフ0 |
| 6 | リンリン#2 | +1 | 13000 | 最後のボルサリーノがブロック→KO |
先に「素の中型」で安い攻撃を受けさせ/カウンターを吐かせ、リーダー効果(+1000)と大型を後段に置くエスカレート型。付与ドン計9はエンド時のドン追加（OP11-067+ST34-001）で回収した再生ドン。6発目が最後のブロッカーを道連れにし、T20の返しを空振りさせた。

### 防御のカード消費（カウンター枚数）
- michiru: **10枚・計13000**（T6:2000 / T8:1000×2 / T10:2000 / T14:2000+2000+1000 / T16:2000 / T18:2000×2 / T20:2000）。20ターンで10枚は異常に安い。
- 内訳の型: ①リーダー効果（ドン-1で+1000）を防御のほぼ毎回使用（1ドン≒カウンター1枚の代替） ②OP11-067(8000)のブロック6回（T8/T10/T12/T14/T16/T18）— **9000/9000/9000/11000級を「ブロック+ちょうど+1000」で全て生還**（例: T14 LOG236-238 9000に8000+2000、T18 LOG354-357 11000に8000+4000） ③5000vs5000級は序盤2回素通し（T4/T18）で手札温存。
- tikumaru: 10枚・計18000。ただしT11にライフ0へ落ちて以降は1発あたり4000消費（T19だけで8000）— 死に体の防御は交換レートが倍化する見本。

### 長期戦のリソース収支（毎ターン、手札とライフの回復・交換）
- 手札: プリン×3（T7/T13/T15、各2ドロー+手札から7000級を踏み倒し登場）とブリュレ×2+OP07-077のサーチで、手札は常時2〜8枚を維持しつつ35回攻撃分の身体を供給。終了時も手札2。
- ライフ: 被弾5（うち1はOP10-112の直接トラッシュ）に対しリンリン×2で+2回復。**常にライフ≥2を維持**（ワンショット圏に一度も入らない）。
- ドン: リーダー-1/リンリン-4/プリン-2/覇海-2 と大量に「支払う」が、ST34-001のドン返却トリガー(+2)とOP11-067エンド効果(+1)で毎ターン回収。支払い系効果を毎ターン回し続けられたのはこの循環のため。
- 対比: tikumaru はデッキ39→8枚（サーチ+ライフ回復エンジンでデッキを燃やす）、回復+8に8枚のカード（キラー×4/ボルサリーノ×4）を使ったが、その回復体はすべて6000級でカタクリの中型に踏まれ、攻撃35回>回復8のレースに敗北。

## 3. 敗者（tikumaru）の敗着
- **T10: 公開情報の覇海を無視した壁の同時再展開**。T9にmichiruがリンリンのコストで覇海を捨てており（LOG95、公開情報）、デッキにコスト6以下2枚KOがあると分かっている状況で ST36-005+キラーを同時展開（LOG125-127）→ T11にOP07-077で2枚目の覇海をサーチされ両KO（LOG144-148）、直後の5連攻撃でライフ4→0（LOG150-174）。壁を1枚ずつ小出しにしていれば覇海1枚との交換で済んだ。
- 補助的敗着: T11の全スルー方針（手札9枚で4発受け）。「ライフ=手札」のキッド流としても、0まで受けると以後は全攻撃がリーサル圏＝毎回4000消費の防御を強制され、T19に枯れた。最後の1点は残すのが正しかった。

## 4. ★CPU移植候補（発火条件→行動）— 固い盤面の崩し方
- **[C1] 壁ゼロ化→最小打点で処理**
  発火: 相手に高パワーのブロッカー/リダイレクト壁（≥8000）がおり、自分がパワー0化・大幅デバフ（ST34-004、神避-8000等）を持つ
  行動: デバフを最高パワーの壁に当て、その壁は「勝てる最小のアタッカー（リーダー含む）」でKOし、大型はリーダー攻撃へ温存
  証拠: T9 リンリン→ST36-005を0化→プリン5000でKO（LOG96-107）、T17 OP10-112(9000ブロッカー)を0化→**リーダー6000**でKO（LOG322-331）
- **[C2] ターン1回シールドの空撃ち（ベイト）**
  発火: 相手の【ターン1回】攻撃対象変更/防御効果（ST36-005リダイレクト等）が未使用、または相手のアクティブなブロッカーが1枚だけ
  行動: 最初に「失っても良い最弱アタッカー」で攻撃してシールド/ブロックを消費させ、その後に本命の攻撃を通す
  証拠: T9 ブリュレ2000がST36-005(0化済)へ攻撃→リダイレクトでOP10-112(9000)に吸われ敗北（計画通り）→直後プリンが本命KO（LOG100-107）
- **[C3] 全体除去→総攻撃バースト**
  発火: 除去（覇海=コスト6以下2枚KO等）で相手の有効ブロッカー数を0にできる
  行動: 除去を攻撃**前**に撃ち、そのターンは全アタッカー+リーダーで攻撃回数を最大化（温存しない）
  証拠: T11 覇海で壁2枚KO→5連攻撃で4点、ライフ4→0（LOG145-174）
- **[C4] 再生ブロッカーの優先KO**
  発火: 相手リーダー/システムが毎ターン、ブロッカーを再生成・再アクティブ化する（キッドリーダー型）
  行動: 「ブロッカー1体残存＝毎ターン攻撃1回無効」と評価し、リーダー連打よりレスト中ブロッカーのKOを優先。勝てる最小のアタッカーを割り当てる
  証拠: T13 リーダー+3ドンでボルサリーノKO・リンリンでキラーKO（LOG219-226）、T9 OP11-067でキラーKO（LOG115-117）
- **[C5] 攻撃順: 受けさせ小→エスカレート**
  発火: 3回以上攻撃できるターン
  行動: 相手が「受ける」であろう素の中型（リーダー同値〜+2000）から先に置き、ドン付与の大型・リーダー効果を後段へ。相手のカウンター計算を1発ごとに悪化させる
  証拠: T19の 7000→9000→10000→10000(リーダー)→12000→13000 順（LOG367-399）、T11も同型
- **[C6] ブロックは「攻撃パワー+1000−ブロッカーパワー」の最小カウンター添え**
  発火: ブロック宣言時
  行動: ブロッカーを死なせない最小のカウンターを同時に切る（ブロッカーが次ターンも壁+アタッカーとして再利用できる場合のみ）
  証拠: OP11-067が6回ブロックして無傷生還（T14 LOG236-238、T18 LOG354-357 ほか）
- **[C7] エンド時アクティブ化の固定則**
  発火: OP11-067型「ターン終了時○枚アクティブ化」の対象選択
  行動: ①ブロッカー自身 ②ドン供給/最大打点キャラ、の優先順で毎回同じに（20ターン全てで OP11-067+ST34-001 を選択: LOG118/175/227/279/341/401）

## 5. 人間の妙手とミス

# m22: michiru(紫カタクリ) ● − ○ tikumaru(赤緑ルフィ OP13-001) — T13

## 1. ゲームストーリー（3行）
1. 赤緑ルフィはサンジ/OP13-118/ゾロ/ウソップの「登場時・エンド時ドン‼アクティブ化」で毎ターン実質コスト超過の展開をしつつ、リーダー効果（ドンレストで+2000/枚）で**手札カウンター0枚のまま**カタクリの攻撃を受け流した。
2. カタクリ側は攻撃がことごとくドン防御で弾かれつつ（6回攻撃で2点のみ）、T9に7000/8000を2連スルーしてライフ3→1、T10のドフラミンゴ全体アタックロックとT12リンリンで延命。
3. T13、ナミ(OP14-031)が唯一のブロッカーOP11-067を寝かせ、サニー号+3ドンの11000**ダブルアタック**でライフ2→0、ゾロ9000×2で蓋をして押し切り。tikumaru終了時手札8枚（開始5枚から増えて勝ち）。

## 2. 勝者（tikumaru）の勝ち筋
### 詰めターン（T13）の攻撃順序とドン配分（LOG124-145）
1. **ナミ登場**（ボニーをサック）→ 相手のアクティブな OP11-067【ブロッカー】と ST34-001 をレスト＝防御層を先に剥がす（LOG127-128）
2. サニー号起動+ドン3付与を**ダブルアタック持ちOP13-118に集中** → 11000（LOG130-131）
3. 11000 D.Atk → リーダー（michiruの手札最大カウンター+3000では5000+3000=8000で不可＝**数学的に不可避**）→ ライフ2枚（2→0）（LOG132-134）
4. ゾロ9000 → 4枚(+4000)で止められる（LOG135-143）
5. ゾロ#2 9000 → 手札カウンター切れ → 勝ち（LOG144-145）
ドン配分の要点: 分散させず**1発を相手の最大カウンター総量の圏外**（11000−5000=6000>相手手札の最大3000）へ押し上げ、残りは素の9000を2本並べる。「確実に通る1発+受けきれない本数」の構成。

### 防御のカード消費（カウンター枚数）
- tikumaru: **手札カウンター0枚**。防御は全てリーダー効果のドンレスト（+2000/ドン）とライフ受け（4→2の2発のみ）。T6/T8/T12のカタクリの攻撃4回をドン払いだけで無効化（LOG33-34/64-65/106-107/116-117）。レストしたドンは次の自分ターンに全回復+サンジ等が追加アクティブ化するため**実質コストほぼゼロ**。手札は5→8枚に増加したまま勝利。
- michiru: 10枚・計12000（T5:2000 / T7:2000 / T9:2000 / T11:2000+1000+1000 / T13:1000×4）+リーダー効果ドン-1×4。それでも受けきれず。

### リソース収支
- ドン: T7にOP13-118（登場時ドン4アクティブ化）で6コストを実質2で展開、以後サニー号のドン付与とサンジ/ゾロのアクティブ化で毎ターン攻撃側は打点増（7000→9000→11000）、防御側はドン払い。攻防両面がドンで完結し手札が減らない。
- 攻撃回数: 11回で6点（うちT13の3本）。カタクリの6回2点と対照的。

## 3. 敗者（michiru）の敗着
**T9の2連スルー（LOG74-81）**。ライフ3・手札にカウンター価値7000分（ST18-001 2000/OP15-069 2000/ST34-002 1000×2/PRB02-010 1000）を持ちながら、サンジ7000（2000で止まる）とリーダー8000（3000で止まる）を素通ししてライフ3→1。盤面には既にダブルアタックのOP13-118が公開されており（T7登場）、以後「11000ダブル1発で即死」の詰み筋が確定した。52.9秒の長考（[117]）の末のスルーで、本人も認識していた分岐点。T12リンリンで2まで戻したが、11000に対する手札の最大カウンターは+3000で数学的に届かず、T13に精算された。

## 4. ★CPU移植候補（発火条件→行動）— 速攻対面でどこからカウンターを切るか
- **[C8] ランプアグロにはカウンター前倒し（now-or-never則）**
  発火: 相手に「登場時/エンド時ドン‼アクティブ化」か【ダブルアタック】を視認済み、かつ自分ライフ≤3
  行動: 必要カウンター値が2000以下で止まる攻撃は**必ず今止める**。相手の攻撃パワーはドン加速でターン毎に増加（本試合7000→9000→11000）し、後で止めるコストは単調増加、最終的に手札上限を超えて不可能になる
  証拠: T5/T7は2000×1で止まった（LOG22-24/53-55）のに、T9のスルー2発（LOG74-81）→T13は6000必要で手札最大3000（LOG132-134）
- **[C9] ライフ下限 = 相手の1ターン最大打点**
  発火: 毎防御判断時
  行動: 相手の「攻撃可能体数+ダブルアタック」から次ターン最大ライフ損失Lmaxを見積り、`自ライフ − 被弾 < Lmax` になる受けはカウンター/ブロックで拒否（ライフをLmax未満に落とさない）
  証拠: T9終了時 guest盤面はリーダー+OP13-118(D.Atk)+サンジ+ゾロ＝最大4-5点。ライフ1は既に詰み圏（boundary9→final）
- **[C10] 防御をブロッカー1枚に依存しない（第2層の維持）**
  発火: 自分の防御計画が単一のアクティブブロッカー頼み
  行動: 相手デッキにレスト付与（ナミOP14-031/舞踏石等）が想定される場合、ブロッカーとは別にカウンター2000相当かライフ1枚分の余裕を残す
  証拠: T12エンドにOP11-067を立てて守る計画→T13ナミ1枚で無効化され敗北（LOG125-128）
- **[C11] （攻め側）リーサル前のブロッカー無力化**
  発火: 詰めターンに相手のアクティブブロッカーが存在
  行動: 攻撃開始**前**に低コストのレスト付与/除去でブロッカーを無力化してから全攻撃（m21のC3と対の「寝かせ版」）
  証拠: T13 ナミ→11000ダブル（LOG125-134）
- **[C12] リーダー防御がドンで払える場合、手札より優先**
  発火: 自リーダーの防御効果コストがドン（レスト/返却）のみ
  行動: 手札カウンターより先にドン払いで受ける（ドンは翌ターン全回復、手札は回復しない）。逆に攻め側評価では「相手の残アクティブドン」を攻撃前に数え、ドン防御可能量+2000を超える打点でのみ攻撃する
  証拠: tikumaru全防御が手札0枚。michiru側はT12に7000/8000をドン防御圏内へ2連投して空振り（LOG105-117）
- **[C13] 詰み回避の全体アタックロック（受け側の非常手段）**
  発火: 自ライフ≤1で相手の攻撃可能体数≥2、かつ全体行動不能系（OP14-069の「レストにできない」等）を保持
  行動: 攻撃を全放棄してでもロックを優先し、来ターンの被攻撃回数を最小化する
  証拠: T10 ドフラミンゴでサンジ/OP13-118/ゾロを行動不能化（LOG84-89）→T11の被攻撃はリーダー1回のみ（LOG95-102）で生還

## 5. 人間の妙手とミス
### CPUなら絶対しない妙手
1. **michiru T10: ライフ1で攻撃0回の10コスト防御ターン**（ドフラミンゴのアタックロック、LOG84-89）。盤面評価関数では「10ドン使って打点0」は最低評価になるが、実際は1ターン完全延命し、リンリンの回復ターンへ繋いだ。
2. **tikumaru: 13ターン手札カウンター0枚の受け**。全防御をドンとライフで払い、手札を「リーサル専用資源」として温存（終了時8枚）。ヒューリスティックのカウンター判定は「止まるなら切る」型になりがちで、この徹底的温存は出ない。
3. **tikumaru T13: ナミを除去でなくレストで使う蓋**。KOできない8コストブロッカーを1コスト分の効果で1ターンだけ確実に消す＝リーサルターンには恒久除去と等価、という等式の理解。

### 人間の明確なミス
1. michiru T9: 上記敗着の2連スルー（LOG74-81）。手札7000分のカウンターを持ちながらライフ3→1。
2. michiru T12: 7000と8000の攻撃を相手のドン防御圏（残ドンで+2000×2可能）へ連続で置いて2連空振り（LOG105-117）。相手の残アクティブドンを数えれば、先にドンを吐かせる順序か攻撃見送りが取れた。
3. michiru T13: ライフ0でゾロ#1に1000×4を全投入→直後のゾロ#2で確定死（LOG138-145）。勝敗には無関係だが、CPUには「残る止め手<残る致死攻撃数なら無駄カウンター抑止」として移植価値あり。

# S/A/B格付けまとめ（CPU移植候補）

**S（勝敗に直結・汎用・実装容易）**
- [C1] 壁ゼロ化→最小打点で処理（m21 T9/T17）— `cpuPickAttack` の対象選択に「デバフ後の壁は最小勝利打点で」
